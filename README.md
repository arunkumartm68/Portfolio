# Portfolio

Personal portfolio of **Arun Kumar T M**: MCA graduate, Linux enthusiast, and web, VR and game developer from Karnataka, India.

**Live site:** https://arunkumartm68.github.io/Portfolio/

## What is on it

- About, build log, skills and contact details
- Projects: [VRHome](https://github.com/arunkumartm68/VRHome), [Marvel VR Suit Gallery](https://github.com/arunkumartm68/Marvel-VR-Suit-Gallery), [Omnitrix Gallery](https://github.com/arunkumartm68/Omnitrix-Gallery), [Face Recognition Attendance System](https://github.com/arunkumartm68/Face-Recognition-Attendance-System) and [Hyprland Dotfiles](https://github.com/arunkumartm68/Hyprland-Dot_files)
- Light and dark themes, and a layout that works on phones

## Built with

Plain HTML, CSS and JavaScript in a single `index.html`. No frameworks and no build step.

## Run locally

```bash
python3 -m http.server 8000
# then open http://localhost:8000
```
